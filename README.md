# hangar

A lightweight module system for remotely operated underwater vehicles, native to
Linux: every function is a process, one manager supervises them all, and modules
exchange data through shared-memory topics that record their own provenance.

Design in progress; start at [docs/00-overview.md](docs/00-overview.md).
